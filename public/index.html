Как подключиться

01

Скопируй ссылку

Нажми COPY на нужной подписке. Для телефона начни с fastest.txt — он лёгкий и импортируется мгновенно.

02

Вставь в клиент

В приложении выбери «Подписка» → «Добавить» → «Из буфера обмена». Клиент сам подтянет весь список серверов.

03

Подключись

Включи туннель и выбери узел с минимальным пингом. Список обновится сам — достаточно нажать «обновить подписку».

05 //

Вопросы

Это обычный текстовый файл со списком серверов (по одному конфигу на строку). Клиент читает файл по ссылке и сам добавляет все узлы. Вам не нужно копировать ключи вручную — одна ссылка заменяет сотни конфигов, и она же автоматически подтягивает свежие серверы.

Примерно раз в час. Точное время обновления и количество рабочих серверов всегда пишутся в шапке самого файла — откройте ссылку в браузере и посмотрите первые строки. Кэширование отключено, поэтому вы всегда получаете актуальную версию.

ALL — максимально полный список, хорош для ПК и мощных клиентов. MOBILE — топ-100, отсортированный по пингу и скорости: меньше весит, быстрее импортируется и не подвешивает мобильные приложения вроде Happ. TOP 500 SECURE — только защищённые транспорты (Reality, TLS, QUIC), без insecure-конфигов.

Возьмите любое зеркало из блоков выше — содержимое идентично. Для России есть отдельное зеркало на Gitverse, которое работает без Cloudflare и GitHub. Кнопка «ПРОВЕРИТЬ» рядом с каждым блоком покажет, какие хосты отвечают из вашей сети прямо сейчас.

Публичные серверы проходят через чужие узлы, поэтому не используйте их для банковских операций и чувствительных данных. Для максимальной приватности берите TOP 500 SECURE: там только VLESS Reality, TLS и QUIC — трафик выглядит как обычный HTTPS, и DPI-системам не за что зацепиться.
